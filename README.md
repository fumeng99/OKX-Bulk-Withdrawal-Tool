# OKX 批量提币工具 v1.1

一键批量处理 OKX 提币请求，支持自定义延迟、多网络选择、费用预估等功能。

## 🚀 快速开始

```bash
cd okx
node server.js
```

启动后在浏览器访问控制台显示的地址，复制 Session Token 填入页面。

## 🔐 安全特性

- **AES-256 加密**: API Key、Secret Key 和 Passphrase 在前端加密后传输
- **Session Token**: 每次启动生成随机令牌
- **本地运行**: 服务仅监听 127.0.0.1
- **HTTPS**: 自动生成自签名证书

## 📋 使用步骤

1. 启动服务 `node server.js`
2. 从控制台复制 Session Token
3. 填写 OKX API Key、Secret Key 和 **Passphrase**
4. 选择币种和网络
5. 输入提币列表 (格式: `地址,金额` 或仅 `地址` 配合统一数量模式)
6. 点击"开始批量提币"

## 💰 手续费说明

OKX 采用 **发送方支付手续费** 模式：
- 对方收到您填写的完整金额
- 手续费从您账户余额中额外扣除
- 例如：提币 1 USDT，手续费 0.8 USDT，您账户扣除 1.8 USDT，对方收到 1 USDT

## 🌐 代理设置

支持多种代理格式：
- `host:port:user:pass` (账密认证)
- `http://host:port`
- `socks5://user:pass@host:port`

## ⚙️ 延迟设置

- **固定延迟**: 每笔提币之间固定等待秒数
- **随机延迟**: 在设定范围内随机等待，更自然

## ⚠️ OKX API 配置

确保您的 API Key 具有以下权限：
- ✅ 读取
- ✅ 提币

**重要设置**：
- 绑定 IP 白名单
- **添加提币地址到地址簿白名单**（必须，否则无法提币）
- 新添加的白名单地址可能需要等待一段时间后才能使用

## 🔧 常见问题

### 提币失败：地址不在白名单
确保在 OKX 网站 → 资产 → 提币 → 地址簿 中添加了目标地址，并等待生效。

### 网络信息加载失败
检查 API Key 是否正确，以及网络连接是否正常。可尝试使用代理。

### 金额精度问题
不同币种和网络有不同的最小提币数量和精度要求，请查看网络信息提示。
